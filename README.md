# Build Your Context · 上下文构建笔记

一个面向中文读者的个人知识网站前端。纯静态页面，没有构建步骤、没有依赖、没有后端。

## 这个仓库是什么

网站的三项核心能力：

1. **浏览** 文章与笔记
2. **搜索** 知识库（关键词全文，覆盖 `data.js` 中的示例文章）
3. **订阅** 邮件（当前仅做邮箱格式校验，**不保存地址、不发送邮件**）

目前是**可直接打开的前端原型**。搜索没有连私人知识库，订阅没有服务端，账户与内容后台均未实现。演示性质的交互在界面上明确标注了「未保存、未发送」，不要把它改成假的成功提示。

## 本地运行

不需要安装任何东西。任选一种：

```bash
# 方式一：直接开文件
open index.html

# 方式二：起静态服务（推荐，行为和线上一致）
python3 -m http.server 8080 --bind 127.0.0.1
# 然后访问 http://127.0.0.1:8080/
```

用方式二是因为 `data.js` 通过普通 `<script>` 引入，直接开 `file://` 也能跑，但路由和相对路径的表现更接近线上。

## 文件结构

| 文件 | 作用 |
|---|---|
| `index.html` | 页面骨架、导航、meta |
| `app.js` | 渲染、搜索、路由、文章目录、表单交互 |
| `data.js` | 内容数据：5 个主题、8 篇示例文章 |
| `styles.css` | 基础样式（纸张色、墨色、暖橙的视觉体系） |
| `refinement.css` | 后加载的调整层：响应式、密度、阅读体验 |
| `assets/` | 本地插图 |
| `original-checksums.json` | 首轮重构前核心文件的校验值，用于确认原始样式未被改坏 |

### 关于两个样式文件的层次

`refinement.css` 在 `styles.css` **之后**加载，用来覆盖后者。这样分层是为了让某一轮改动的范围可核对，不是为了长期保持。

如果你要做的改动比较大，**可以把两者合并回一个 `styles.css`**，只要同步删除 `index.html` 里多出来的那个 `<link>`。合并后请顺手删掉 `original-checksums.json`，它就没有意义了。

## 编辑内容

文章和主题都在 `data.js` 里，是一个普通对象数组，改完刷新即可。字段含义见文件头部注释（若有疑问，按现有 8 篇示例的结构照写即可）。

**不要把私有笔记直接丢进 `data.js`。** 这个仓库是公开的，进去的内容等同于公开发布。

## 已验证的视口

改样式后请至少检查这四个宽度：

| 宽度 | 场景 |
|---|---|
| 1440 | 桌面常规 |
| 768 | 平板 |
| 390 | 手机主流 |
| 360 | 手机窄屏 |

已知边界：只在浏览器模拟视口下验证过，**没有做真机、微信内置浏览器的实测**。

## 贡献约定

- 不引入构建步骤和前端框架。这个项目的价值之一是「拿到就能开」。
- 不加依赖。需要图标就画 SVG，需要交互就写原生 JS。
- 提交前在浏览器里跑一遍：搜索、主题筛选、无结果恢复、阅读后返回保留搜索词、手机目录展开收起、订阅邮箱校验。
- 中文文案保持克制，不堆营销词。
